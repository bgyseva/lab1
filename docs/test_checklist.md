\## Чек-лист CL-REG-01 (минимальный набор перед релизом)



\### Счастливые пути



| ID | Проверка | Ожидаемый результат |

|----|----------|---------------------|

| CL-01 | Запуск программы | Программа запускается без ошибок, отображается приглашение к вводу |

| CL-02 | Создание задачи | Задача создается, появляется в списке, получает ID |

| CL-03 | Просмотр списка задач | Список отображает все созданные задачи с ID, названием и статусом |

| CL-04 | Изменение статуса задачи | Статус изменяется на допустимый, отображается в списке |

| CL-05 | Поиск по ключевому слову | Поиск находит задачи, содержащие ключевое слово |

| CL-06 | Сохранение в JSON | После создания задачи файл `tasks.json` создается/обновляется |

| CL-07 | Загрузка после перезапуска | После перезапуска программы все задачи восстанавливаются |



\### Ошибочные сценарии



| ID | Проверка | Ожидаемый результат |

|----|----------|---------------------|

| CL-08 | Создание задачи с пустым названием | Ошибка: "Название задачи не может быть пустым", задача не создается |

| CL-09 | Изменение статуса на недопустимый | Ошибка: "Недопустимый статус", статус не меняется |

| CL-10 | Поиск по несуществующему слову | Возвращается пустой список или сообщение "Ничего не найдено" |

| CL-11 | Первый запуск без файла `tasks.json` | Программа запускается, список пуст, при создании задачи файл создается |

| CL-12 | Изменение статуса несуществующей задачи | Ошибка: "Задача с ID X не найдена" |

| CL-13 | Поиск с пустым запросом | Ошибка: "Поисковый запрос не может быть пустым" |

| CL-14 | Создание задачи с названием, превышающим 30 символов | Ошибка: "Название слишком длинное (макс. 30 символов)" |

\## Выполнение чек-листа



\### Инструкция по выполнению

1\. Активировать виртуальное окружение: `.venv\\Scripts\\activate`

2\. Запустить модуль: `python src/app.py`

3\. Выполнять проверки в порядке, указанном в чек-листе

4\. Фиксировать результат каждой проверки

5\. При обнаружении дефекта — зафиксировать и создать Issue
